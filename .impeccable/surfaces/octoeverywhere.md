# OctoEverywhere page

Mode: Operate.

The operator connects a Gadget account and camera access, enables monitoring for selected printers, and checks current status and recent activity. Use the existing OE account-page visual world: charcoal canvas, darker floating boxes, white text, blue links and purple actions. The first viewport identifies the product and shows the next setup action, or the connected account and first printers when setup is complete.

Preserve automatic startup with a configurable warm-up estimate and per-printer automatic pause off by default. Do not introduce a manual first-layer confirmation. Credentials and camera configuration errors need recoverable, specific messages. Empty and read-only views must remain useful.

Evidence: `ui/src/styles.css`, `ui/src/page.svelte`, `ui/src/account-settings.svelte`, `ui/src/printer-card.svelte`, and the original assets in `ui/src/assets/`.
